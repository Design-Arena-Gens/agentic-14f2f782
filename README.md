# AI Automation Advisor

Веб‑приложение подсказывает, как автоматизировать повседневные бизнес‑процессы с помощью Zapier, Make и OpenAI. Пользователь описывает рутину — сервис формирует компактную таблицу со связками, ожидаемой экономией времени и оценкой сложности внедрения.

Продакшн: https://agentic-14f2f782.vercel.app

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- npm

### Установка и запуск
```bash
npm install
npm run dev
```
Откройте `http://localhost:3000`.

## 📁 Структура
```
├── app/                 # Страницы App Router и layout
├── components/          # UI-компоненты
├── lib/                 # Бизнес-логика рекомендаций
├── public/              # Статика
├── tailwind.config.ts   # Tailwind CSS
└── package.json
```

## 🧠 Логика рекомендаций
- Ключевые слова из описания задач мапятся на готовые шаблоны автоматизации.
- Каждая связка включает стек инструментов, экономию времени и оценку сложности (1–10).
- Если явных совпадений нет, показываются универсальные ускорители.

## 🛠️ Скрипты
- `npm run dev` — режим разработки
- `npm run lint` — ESLint
- `npm run build` — продакшн-сборка
- `npm start` — запуск собранного приложения
